# Assignment Management System

A responsive assignment management application designed to help university students manage coursework, deadlines, and academic workload in one place.

## Overview

The system integrates with the **Canvas LMS API** to automatically retrieve assignments, deadlines, course information, calendar events, and announcements. It aims to reduce manual data entry and the need to switch between Canvas, calendars, email, and other task-management tools.

## Key Features

* 📚 Canvas API integration
* 📅 Interactive calendar with daily, weekly, and monthly views
* 📊 Assignment workload and progress tracking
* 🔔 Configurable deadline notifications
* 🔎 Assignment search, filtering, and sorting
* 📈 Workload and study-progress analytics
* 🔄 Automatic synchronisation with Canvas
* 🔐 Secure user authentication
* 📱 Responsive design for desktop and mobile

## Technology

* **Frontend:** React
* **Backend:** C#
* **API:** Canvas LMS API
* **API Testing:** Postman
* **Development:** Visual Studio Code
* **Version Control:** GitHub
* **AI Assistance:** GitHub Copilot & Claude

## Quality Assurance

Software quality is a core focus of the project. Testing will include:

* Unit testing
* Integration testing
* System/end-to-end testing
* Usability testing
* Performance testing
* Security testing
* Compatibility testing

Requirements will be linked to test cases through a traceability matrix, while defects will be tracked using GitHub Issues.

## Project Goal

The goal is to provide students with a reliable and user-friendly planning tool that gives them a single view of their academic workload and helps reduce the risk of missed deadlines.
